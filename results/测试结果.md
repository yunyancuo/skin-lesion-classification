# 测试结果

模型：改进版 ResNet18（ImageNet 预训练 + 类别加权采样 + 强增强），权重 `outputs/pretrained_weighted/checkpoints/best.pth`。

测试集：**1001 张图**，按病灶（lesion_id）分组划分，训练过程完全不可见。评估代码 `src/evaluate.py`，逐图预测由 `src/make_test_results.py` 生成。

## 1. 总体指标

| 指标 | 基线（scratch） | 改进版 | 提升 |
|---|---|---|---|
| Accuracy | 0.7772 | **0.8272** | +5.0 pt |
| Balanced Accuracy | 0.6146 | **0.7261** | +11.2 pt |
| Macro F1 | 0.6071 | **0.7079** | +10.1 pt |
| Macro AUC (OvR) | 0.9384 | **0.9610** | +2.3 pt |

逐张统计：1001 张中 **828 张判对、173 张判错**。

## 4. 复现命令

**注意：数据集（约 3GB）和 PyTorch 环境在训练服务器上，本地电脑没有装 torch、也没有数据，以下命令要在服务器上跑**（登录后 `cd ~/ham`），不要在本地仓库目录直接运行：

```bash
# 1) 登录服务器（或在服务器终端上），进入项目目录
ssh <服务器登录命令>      # 服务器地址与账号见项目组内部说明，勿写入公开仓库
cd ~/ham

# 2) 测试集评估（约 20 秒，输出指标 + 每类报告 + 混淆矩阵）
python3 src/evaluate.py --weights outputs/pretrained_weighted/checkpoints/best.pth

# 3) 逐图预测明细 + 预测示例图
python3 src/make_test_results.py --weights outputs/pretrained_weighted/checkpoints/best.pth --out-dir results
```
