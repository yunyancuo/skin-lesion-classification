# 测试结果

模型：改进版 ResNet18（ImageNet 预训练 + 类别加权采样 + 强增强），权重 `outputs/pretrained_weighted/checkpoints/best.pth`。

测试集：**1001 张图**，按病灶（lesion_id）分组划分，训练过程完全不可见。评估代码 `src/evaluate.py`，逐图预测由 `src/make_test_results.py` 生成。

## 1. 总体指标

| 指标 | 基线（scratch） | 改进版 | 提升 |
|---|---|---|---|
| Accuracy | 0.7772 | **0.8272** | +5.0 pt |
| Balanced Accuracy | 0.6146 | **0.7261** | +11.2 pt |
| Macro F1 | 0.6071 | **0.7079** | +10.1 pt |
| Macro AUC (OvR) | 0.9384 | **0.9610** | +2.3 pt |

逐张统计：1001 张中 **828 张判对、173 张判错**。

## 2. 每类召回率（改进版 vs 基线）

| 类别 | 测试图数 | 基线 | 改进版 | 变化 |
|---|---|---|---|---|
| akiec | 34 | 0.324 | 0.324 | ±0 |
| bcc | 50 | 0.580 | 0.740 | +16 pt |
| bkl | 107 | 0.551 | 0.720 | +17 pt |
| df | 8 | 0.500 | 0.750 | +25 pt |
| mel | 113 | 0.442 | 0.646 | +20 pt |
| nv | 674 | 0.905 | 0.904 | ±0 |
| vasc | 15 | 1.000 | 1.000 | ±0 |

黑色素瘤（mel）113 张中判错 40 张：24 张被判成 nv、15 张被判成 bkl、1 张被判成 akiec——误判去向与报告第四章混淆矩阵分析一致。

## 3. 附件文件

| 文件 | 说明 |
|---|---|
| `test_predictions.csv` | 逐图预测明细：image_id、lesion_id、真实类、预测类、预测置信度、是否正确（共 1001 行，可抽查任意一张） |
| `prediction_examples.png` | 预测示例：上排 4 张判对，下排 4 张判错（含 mel/bcc 等恶性类典型错误） |

## 4. 复现命令

```bash
# 测试集评估（输出指标 + 每类报告 + 混淆矩阵）
python src/evaluate.py --weights outputs/pretrained_weighted/checkpoints/best.pth

# 逐图预测明细 + 预测示例图
python src/make_test_results.py --weights outputs/pretrained_weighted/checkpoints/best.pth --out-dir results
```

完整训练与评估流程见仓库 `README.md` 与 `实验报告.md`。
